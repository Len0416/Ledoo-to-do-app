# Ledoo-to-do-app
📌 Descripción del proyecto: Ledoo Ledoo es una aplicación web de gestión de tareas inspirada en Microsoft To Do, diseñada para ofrecer una experiencia intuitiva, visualmente atractiva y altamente personalizable. Su objetivo es ayudar a los usuarios a organizar sus actividades diarias mediante listas, etiquetas, prioridades y fondos temáticos.
